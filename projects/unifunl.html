Unifunl

  • Tech Stack: Terraform, Azure Kubernetes Service (AKS), Kubernetes, Falco, Trivy, GitHub Actions, Prometheus, Grafana, Alertmanager, NGINX Ingress, PostgreSQL, Redis, k6
  • Context: INSAT professional project (team of 3) for Unifunl, a B2B SaaS platform of conversational AI agents for MENA e-commerce
  • Github URL: Project Link

Automated and secured the deployment of a cloud-native microservices platform: migrated it from Azure Container Apps to AKS with Terraform, added runtime threat detection with Falco and image scanning with Trivy, and validated the gains with k6 load tests. Delivered in 45 days.

Starting point: latency collapsed under traffic spikes (p95 up to 5.78 s), no runtime security, infrastructure provisioned by hand through the portal and CLI, and no alerting.

Key Contributions:

  • Architecture (my part): designed a 3-layer target on AKS – Terraform for the infrastructure, Kubernetes for the 7 services (3 HPAs, 4 NetworkPolicies, NGINX Ingress with TLS), and Falco for runtime security
  • Infrastructure as code (my part): Terraform modules for the AKS cluster, PostgreSQL, Redis and the container registry, with remote state and locking in Azure Blob Storage, validated and sensitive variables, and Workload Identity (OIDC) so pods authenticate to Azure AD with no static secret
  • DevSecOps (my part): deployed Falco as an eBPF DaemonSet in audit-only mode with 3 custom rules – shell spawned in a container, writes to sensitive paths, and privilege escalation. Defence in depth with NetworkPolicy isolation, TLS in transit, secrets injected through secretKeyRef, and a partial ISO/IEC 27001 alignment
  • CI/CD (team): 11 GitHub Actions workflows built on one reusable template, with Trivy scanning every image for HIGH/CRITICAL vulnerabilities (the build fails on an unfixed CVE) and scanning the Kubernetes manifests, Terraform and workflows; images tagged by commit SHA, production deployment behind an approval gate, automatic rollback if a rollout fails
  • Observability (team): Prometheus, Grafana and Alertmanager with 5 alert rules
  • Measured results (team): k6 benchmarks before and after the migration – p95 latency down 64% under normal load, up to 94% lower on the data layer, 3.7x more sustained throughput under stress, and the spike collapse eliminated
