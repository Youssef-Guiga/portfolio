Unifunl

  • Tech Stack: Terraform, Azure App Services, AKS, Kubernetes, k6
  • Github URL: Project Link

Migrated app from Azure App Services to AKS using Terraform, improving scalability and reliability; validated performance with k6.

Key Contributions:

  • Wrote Terraform modules to provision the AKS cluster, database, and Redis cache as reproducible infrastructure-as-code, with remote state locking in Azure Blob Storage
  • Migrated the platform's core services (front, account, transactor, collaborator) to AKS, containerizing and deploying them behind Kubernetes with Workload Identity for secretless Azure authentication
  • Benchmarked performance before/after the migration with k6, comparing Azure App Services and AKS under load
