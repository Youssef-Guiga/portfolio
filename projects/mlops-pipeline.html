MLOps Spam Detection Pipeline

  • Tech Stack: FastAPI, React, Docker, SQLite
  • API Repo: spam-detection-api
  • UI Repo: spam-detection-ui
  • project description: pdf

An end-to-end MLOps pipeline for email spam classification, with a FastAPI backend serving the model and a React frontend for submitting emails for analysis.

Key Features:

  • FastAPI backend with dedicated modules for the model, training, and a scheduler for periodic retraining
  • Feedback loop: predictions and user feedback are logged to a database and fed back into retraining
  • React frontend supporting both single and batch email checks against the API
  • Both services containerized with Docker for local development and deployment
