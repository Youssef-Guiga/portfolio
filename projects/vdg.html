IEEE RAS INSAT NRW Event Website

  • Tech Stack: Angular, TypeScript
  • website overview: Project Link

Official website for the IEEE Robotics & Automation Society INSAT Chapter's National Robotics Weekend (NRW), developed using Angular and TypeScript. This platform serves as the central hub for event information, participant interaction, and administrative management.

Key Features:

  • Fully functional user registration system with dynamic form validation
  • Dedicated admin dashboard for real-time monitoring of participants, teams, and challenge assignments
  • Integrated chatbot for handling event-related inquiries
  • Responsive and accessible design across all devices

Technical Highlights:

  • Modular Angular component architecture for scalable development
  • Deployed and hosted registration and backend services on Google Cloud Platform using Compute Engine (VMs), Cloud Storage (buckets), and secured API endpoints
  • Dashboard enables centralized participant data management, including team members, selected challenges, and submitted keynotes
  • SEO-optimized for visibility and indexability
