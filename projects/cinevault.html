CineVault

  • Tech Stack: NestJS, TypeORM, MySQL, Angular 19, Docker, Kubernetes, Nginx
  • Github URL: Project Link

A full-stack movie theater management platform, with a NestJS/TypeORM API backed by MySQL and an Angular 19 standalone frontend.

Key Features:

  • JWT authentication with role-based access (admin/manager)
  • Movie and genre catalog management, plus screening, booking, review, and reporting modules
  • Kubernetes manifests with an HPA for backend autoscaling, and Docker Compose for local development
  • CI pipeline (GitHub Actions) running lint, unit tests, and build on both backend and frontend, with k6 smoke tests
